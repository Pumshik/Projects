# Unordered Map (C++)

Реализация хеш-таблицы (аналога `std::unordered_map`) с полной поддержкой move-семантики, аллокаторов и STL-совместимых итераторов.

## Архитектура и дизайн

### Структура данных
- **Вектор корзин**: `std::vector<Node*>` для быстрого доступа по хешу
- **Двусвязный список**: поддержка упорядоченного обхода всех элементов
- **Узлы Node**: содержат данные, указатели для цепочки и списка, кешированный хеш

### Шаблонные параметры
```c++
template <typename Key,
typename Value,
typename Hash = std::hash<Key>,
typename Equal = std::equal_to<Key>,
typename Alloc = std::allocator<std::pair<const Key, Value>>>
class UnorderedMap;
```
## Основной функционал
### Операции доступа
| Метод | Сложность | Особенности |
|-------|-----------|-------------|
| `operator[](const Key&)` | O(1) в среднем | Создает Value по умолчанию, если ключ отсутствует |
| `at(const Key&)` | O(1) в среднем | Кидает `std::out_of_range` при отсутствии ключа |
| `find(const Key&)` | O(1) в среднем | Возвращает `end()` если элемент не найден |

### Вставка элементов
| Метод | Особенности |
|-------|-------------|
| `insert(const NodeType&)` | Копирующая вставка |
| `insert(NodeType&&)` | Перемещающая вставка |
| `emplace(Args&&...)` | Конструирование элемента на месте |
| `insert(InputIt, InputIt)` | Вставка диапазона с поддержкой move-итераторов |

### Удаление элементов
| Метод | Сложность | Гарантии |
|-------|-----------|----------|
| `erase(iterator)` | O(1) в среднем | Не инвалидирует остальные итераторы и указатели |
| `erase(iterator, iterator)` | O(n) | Поэлементное удаление диапазона |

### Управление памятью и производительностью
| Метод | Назначение |
|-------|-----------|
| `reserve(size_t)` | Гарантирует достаточную емкость для N элементов |
| `rehash(size_t)` | Явное изменение размера хеш-таблицы |
| `load_factor()` | Текущий коэффициент загрузки |
| `max_load_factor(float)` | Установка максимального коэффициента загрузки |

## Ключевые особенности реализации

### 1. Поддержка move-семантики
- **Полная поддержка move-конструкторов и move-операторов**
- **Эффективная вставка rvalue** без лишних копирований
- **Перемещение между контейнерами** с сохранением валидности указателей

### 2. Аллокатор
- **Использование `allocator_traits`**
- **Поддержка свойств аллокаторов**:
  - `propagate_on_container_copy_assignment`
  - `propagate_on_container_move_assignment`
  - `propagate_on_container_swap`
  - `select_on_container_copy_construction`
- **Zero-overhead для пустых аллокаторов** через `[[no_unique_address]]`

### 3. Гарантии безопасности исключений
- **Строгая гарантия** для большинства операций
- **Базовые гарантия** для операций с рехешированием
- **Корректная обработка исключений** от хеш-функций и сравнений

### 4. Итераторы
- **Forward iterator**
- **Линейный обход**
- **Инкрементация за O(1)**
- **Константные и неконстантные**
- **Итераторы не инвалидируются**

### 5. Оптимизации
- **Кеширование хешей** для избежания повторных вычислений
- **Удвоение размера при переполнении**
- **Локальность данных** за счет отдельного списка для обхода

## Производительность

| Операция | В среднем | В худшем случае |
|----------|-----------|-----------------|
| Вставка | O(1) | O(n) |
| Удаление | O(1) | O(n) |
| Поиск | O(1) | O(n) |
| Обход всех элементов | O(n) | O(n) |
